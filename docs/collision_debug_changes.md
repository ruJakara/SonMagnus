# Отладка коллизий - изменения

## Исправлено

### 1. **EnemyBase.gd** - Поворот хитбоксов врага
Метод `face_target()` теперь поворачивает не только спрайт, но и все хитбоксы:
- `Hurtbox` (зона получения урона)
- `Attack` (зона атаки врага)
- `Back` (зона спины)

**Механизм**: Меняется `position.x` хитбоксов (аналогично игроку), сохраняя абсолютное значение базовой позиции и умножая на направление (-1 или 1).

### 2. **EnemyBase.tscn** - Исправлены collision layers
**Было**: `collision_layer = 255` (все слои одновременно!)
**Стало**: `collision_layer = 16` (только слой врагов)

Это критично! Неправильные слои приводят к тому, что физический движок не видит коллизий.

### 3. **Добавлены инструменты отладки**

#### a) `CollisionDebugger.gd` - Текстовый лог
Выводит в консоль при старте игры:
- Все узлы игрока и врагов
- Их collision_layer/mask в двоичном формате
- Позиции хитбоксов
- Размеры CollisionShape2D
- Состояние monitoring/monitorable

**Использование**: Автоматически запускается при `Config.DEBUG_LOGS = true`

#### b) `HitboxDebugDraw.gd` - Визуальная отладка
Рисует в реальном времени:
- Хитбоксы игрока (голубые)
- Хитбоксы врагов (красные)
- Зоны атак врагов (оранжевые)
- Текст с названием и слоями (L:layer M:mask)

**Управление**: Ставить/убирать галочку `enable_hitbox_debug` в инспекторе узла `HitboxDebugDraw` в main.tscn

### 4. **EnemyBase._ready()** - Улучшенные логи
Теперь выводит:
- Имя врага
- Наличие Hurtbox
- collision_layer, collision_mask, monitorable
- Глобальную позицию Hurtbox

## Как использовать

1. **Запустите игру** с `Config.DEBUG_LOGS = true`
2. **Посмотрите консоль** - там будет блок:
   ```
   ============================================================
   [CollisionDebugger] ДИАГНОСТИКА КОЛЛИЗИЙ
   ============================================================
   [ИГРОК] Player
     Позиция: (x, y)
     Collision Layer: 2 (bin: 00000010)
     ...
   [ВРАГИ] Найдено: 1
   ...
   ```

3. **Посмотрите на экран** - хитбоксы отрисованы полупрозрачными кругами/прямоугольниками

4. **Подойдите к врагу** и атакуйте - в консоли будут логи:
   ```
   [PlayerCombat] Найдено целей: 1
   [PlayerCombat] Цель #0: EnemyBase (группы: [enemies, ...])
   ```

## Что проверять

### ✅ Правильные значения
- **Player Hitbox**: Layer=8, Mask=16
- **Enemy Hurtbox**: Layer=16, Mask=8, Monitorable=true
- **Позиции**: Игрок и враг должны быть на расстоянии < (radius_player + radius_enemy)

### ❌ Частые ошибки
- Layer/Mask = 0 (коллизии отключены)
- Monitorable = false у Hurtbox (не видим для Area2D.get_overlapping_areas())
- Слишком большое расстояние между объектами
- Отрицательный scale (ломает физику)

## Следующие шаги
Если урон всё ещё не проходит после этих исправлений:
1. Проверьте логи CollisionDebugger - там будет видно несоответствие слоёв
2. Проверьте визуально - пересекаются ли хитбоксы на экране
3. Проверьте `[PlayerCombat] Найдено целей: N` - если N=0, значит get_overlapping_areas() не видит врага
